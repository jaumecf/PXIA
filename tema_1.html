Aquest tema acompanya l'alumnat des dels conceptes fonamentals de la programació fins a la creació, modificació i destrucció d'objectes interactius directament al motor Unity.

1

Visió General d'un Script de Unity

A Unity escrivim el nostre codi en C#, un llenguatge Orientat a Objectes (POO) adoptat massivament a la indústria dels videojocs. Podem pensar en els scripts com a "guions de comportament" que associem als objectes de la nostra escena (GameObjects).

Normes i Convencions Importants

  • Ubicació: Es recomana crear una carpeta anomenada Scripts dins de Assets/ per a mantenir el projecte organitzat.
  • Nomenclatura: El nom del fitxer i el nom de la classe han de ser exactament iguals (ex. Player.cs conté public class Player). Si no coincideixen, Unity no podrà carregar el component.
  • Estil: Els noms de les classes utilitzen la convenció UpperCamelCase (o PascalCase).

Estructura per Defecte d'un Script (`MonoBehaviour`)

Quan creem un script nou, Unity genera automàticament una classe pública que deriva o hereta de la classe base MonoBehaviour. 

using UnityEngine; // Permet accedir a l'API del motor de Unity

public class Player : MonoBehaviour
{
    // Es crida automàticament una sola vegada quan s'inicia el joc
    void Start()
    {
        Debug.Log("El jugador ha estat creat a l'escena.");
    }

    // Es crida automàticament a cada fotograma (frame) del joc
    void Update()
    {
        // Útil per a detectar entrades de teclat o actualitzar posicions
    }
}

Variables, Tipus de Dades i Encapsulació

Una variable és un contenidor a la memòria de l'ordinador que guarda una informació que pot canviar durant l'execució del joc (per exemple, la vida, el nom o la velocitat d'un personatge).

Elements d'una Declaració

  • Modificador d'àmbit: public o private.
  • Tipus de dada: Quin tipus d'informació guarda.
  • Nom: Segueix la convenció camelCase.
  • Valor inicial (opcional): Assignació inicial.

Tipus de Dades BÀSICS

  • int: Nombres enters (ex. int ammoCount = 30;)
  • float: Nombres decimals (sempre amb 'f', ex. float speed = 5.5f;)
  • string: Cadenes de text (ex. string myName = "Heroi";)
  • bool: Valor verdader o fals (ex. bool hasAllKeys = false;)

Bones Pràctiques i Encapsulació en C# / Unity

  • private per defecte: Les variables han de ser privades tret que altres scripts necessitin accedir-hi directament. Si no s'indica modificador, C# la considera privada per defecte.
  • Atribut [SerializeField]: Permet veure i modificar una variable private des de l'Inspector de Unity sense exposar-la a altres scripts.
  • Convenció de Microsoft .NET: Utilitzar el prefix _ per a variables privades de classe (ex. private float _speed;) per a identificar-les ràpidament al codi.

Sentències Condicionals i Control de Flux

Les condicionals permeten prendre decisions al codi: executar certes seccions de programa només si es compleix una condició.

Operadors Relacionals

== (Igual a)

!= (Diferent de)

>= (Major o igual)

<= (Menor o igual)

Operadors Lògics

&& (AND - Es compleixen totes les condicions)

|| (OR - Es compleix almenys una condició)

! (NOT - Inverteix el valor booleà)

Estructura `if / else if / else` i Sentència `switch`

// Exemple d'Avaluació de Notes
float nota = 7.5f;

if (nota >= 0.0f && nota < 5.0f) {
    Debug.Log("Insuficient");
} else if (nota >= 5.0f && nota < 6.0f) {
    Debug.Log("Suficient");
} else if (nota >= 6.0f && nota < 7.0f) {
    Debug.Log("Bé");
} else if (nota >= 7.0f && nota < 9.0f) {
    Debug.Log("Notable");
} else if (nota >= 9.0f && nota <= 10.0f) {
    Debug.Log("Excel·lent");
} else {
    Debug.Log("Error: Nota no vàlida");
}

// Sentència switch per a valors concrets o estats
int weaponID = 2;
switch (weaponID)
{
    case 1:
        Debug.Log("Arma: Pistola");
        break;
    case 2:
        Debug.Log("Arma: Ganivet");
        break;
    default:
        Debug.Log("Sense arma assignada");
        break;
}

Sentències Iteratives (Bucles)

Els bucles ens permeten repetir un bloc de codi diverses vegades. Són fonamentals en videojocs per a recórrer llistes d'enemics, actualitzar inventaris o processar explosions.

Bucle `for`

Utilitzat quan coneixem exactament el número d'iteracions.

for (int i = 0; i < 10; i++)
{
    Debug.Log(i);
}

Bucle `while` / `do-while`

S'executa mentre una condició sigui certa. ¡Alerta amb bucles infinits!

while (health > 0)
{
    // Execució
}

Bucle `foreach`

Dissenyat especialment per a recórrer tots els elements d'un Array o Col·lecció.

foreach (var item in items)
{
    Debug.Log(item);
}

Arrays i Estructures de Dades

Un Array és una col·lecció ordenada d'elements del mateix tipus amb una mida fixa. A Unity podem assignar tant la mida com els valors directament des de l'Inspector. 

public string[] names; // Declaració sense inicialitzar
public string[] items = new string[5]; // Array de 5 elements buits
public int[] ages = { 5, 10, 15, 33 }; // Inicialització directa

void Start()
{
    Debug.Log(ages[1]); // Accedeix al segon element (índex 1) -> Mostra 10
    items[0] = "Espasa"; // Assigna valor al primer element
    Debug.Log("Mida de l'array: " + ages.Length); // Propietat .Length
}

Mètodes, Paràmetres i Retorn de Valors

Els mètodes o funcions permeten dividir el codi en blocs modulars, reutilitzables i nets. Es fan servir per a dissenyar les accions del joc (ex. Attack(), TakeDamage(), CalculateScore()). 

// Mètode sense retorn (void) i amb paràmetres
public void ChangeColor(GameObject obj, Color newColor)
{
    obj.GetComponent().material.color = newColor;
}

// Mètode amb retorn d'un tipus de dada (int)
public int Sum(int a, int b)
{
    return a + b;
}

Programació Orientada a Objectes (POO): Herència i Polimorfisme

A Unity podem crear les nostres pròpies classes personalitzades per a representar conceptes complexos com dades d'armes, ítems o jugadors. Per a poder visualitzar classes personalitzades a l'Inspector cal utilitzar l'atribut [System.Serializable].

Nivells d'Accés i Herència

public Accessible des de qualsevol script.
private Accessible només dins la mateixa classe.
protected Accessible dins la classe i per les classes que hereten d'ella.

Exemple de Mètodes Virtuals (`virtual`) i Sobrescrits (`override`)

// Classe Base
[System.Serializable]
public class Item 
{
    [SerializeField] protected string itemName;
    
    public virtual void MyTreat() 
    {
        Debug.Log("Soc un ítem general.");
    }
}

// Classe Derivada (Herència)
public class Fruit : Item 
{
    public override void MyTreat() 
    {
        Debug.Log("Soc una fruita i restauro la salut!");
    }
}

Anàlisi d'Algorismes i Resolució de Problemes

Analitzem problemes típics com la generació d'elements aleatoris sense repetició (per exemple, assignar races a eliminar en una missió).

Exercici d'Anàlisi d'Algorisme 

private bool Contiene(int n, int[] randomsGenerados)
{
    bool result = false;
    for (int i = 0; i < randomsGenerados.Length; i++)
    {
        if (n == randomsGenerados[i])
        {
            result = true;
            break;
        }
    }
    return result;
}

Pràctica Directa a Unity: GameObjects, Transform i Destroy

Fins ara hem après les bases de C#. És el moment de connectar aquests coneixements amb el motor Unity. En aquesta secció aprendrem a instanciar nous objectes en temps d'execució, modificar la seva posició/escala/rotació a través del Transform i eliminar-los de la memòria amb Destroy.

Conceptes Tècnics Clau

Instantiate() Crea una còpia (instància) d'un Prefab o GameObject en temps d'execució. 
Instantiate(prefab, position, rotation);
Transform Component obligatori de tot GameObject. Controla la posició, rotació i escala 3D/2D. 
transform.position += Vector3.up * speed;
Destroy() Elimina un GameObject de la memòria. Pot rebre un temps de retard opcional en segons. 
Destroy(gameObject, 3.0f);
