Fonaments d'IA i Percepció Sensorial

A diferència de la IA acadèmica (que busca la solució matemàticament perfecta per guanyar sempre), la IA per a videojocs busca crear la il·lusió d'intel·ligència: agents creïbles, reactius i divertits d'enfrontar sense fer "trampes" (com accedir directament al transform.position del jugador a través de parets).

ARQUITECTURA D'UN AGENT INTEL·LIGENT (AGENT LOOP)
1. SENSE (Percepció) 2. THINK (Decisió / Memòria) 3. ACT (Moviment / Acció)

Sistema de Visió (Con FOV)

Combina 3 filtres: proximitat (Physics.OverlapSphere), angle de visió (Vector3.Angle) i comprovació d'obstacles (Physics.Raycast amb LayerMask).

Sistema d'Oïda (Esdeveniments)

Propagació de soroll per radi quan el jugador corre o llença un objecte. Permet detectar perills fora del camp visual.

Memòria a Curt Termini

Emmagatzema l'últimaPosicióConeguda i un temporitzador de sospita perquè l'enemic investigui abans d'abandonar la recerca.

Exemple de Codi: Con de Visió amb Línia de Visió i Gizmos

using UnityEngine;

public class FieldOfViewSensor : MonoBehaviour
{
    [Header("Paràmetres de Visió")]
    public float viewRadius = 12f;
    [Range(0, 360)] public float viewAngle = 90f;

    [Header("Màscares de Capes")]
    public LayerMask targetMask;
    public LayerMask obstacleMask;

    public Transform VisibleTarget { get; private set; }
    public Vector3 LastKnownPosition { get; private set; }

    private void Update()
    {
        DetectTargets();
    }

    private void DetectTargets()
    {
        VisibleTarget = null;
        // 1. Filtre de distància
        Collider[] targetsInRadius = Physics.OverlapSphere(transform.position, viewRadius, targetMask);

        foreach (Collider targetCol in targetsInRadius)
        {
            Transform target = targetCol.transform;
            Vector3 dirToTarget = (target.position - transform.position).normalized;

            // 2. Filtre d'angle (Con de visió)
            if (Vector3.Angle(transform.forward, dirToTarget) < viewAngle / 2f)
            {
                float distToTarget = Vector3.Distance(transform.position, target.position);

                // 3. Filtre d'obstacles (Línia de visió directa)
                if (!Physics.Raycast(transform.position, dirToTarget, distToTarget, obstacleMask))
                {
                    VisibleTarget = target;
                    LastKnownPosition = target.position;
                    break;
                }
            }
        }
    }

    // Dibuix de depuració visual a l'Editor de Unity
    private void OnDrawGizmos()
    {
        Gizmos.color = VisibleTarget != null ? Color.red : Color.green;
        Gizmos.DrawWireSphere(transform.position, viewRadius);

        Vector3 leftBoundary = Quaternion.Euler(0, -viewAngle / 2f, 0) * transform.forward * viewRadius;
        Vector3 rightBoundary = Quaternion.Euler(0, viewAngle / 2f, 0) * transform.forward * viewRadius;

        Gizmos.DrawLine(transform.position, transform.position + leftBoundary);
        Gizmos.DrawLine(transform.position, transform.position + rightBoundary);

        if (VisibleTarget != null)
            Gizmos.DrawLine(transform.position, VisibleTarget.position);
    }
}

Moviment Autònom: Steering Behaviors i Flocking

Formulats per Craig Reynolds, els Steering Behaviors generen moviment orgànic i fluid aplicant forces d'acceleració sobre una velocitat actual (evitant girs robòtics instantanis). La fórmula fonamental és:

Steering Force = Desired Velocity − Current Velocity

Comportaments Individuals

  • Seek / Flee: Accelera cap a un objectiu o en direcció oposada a una amenaça.
  • Arrive: Com Seek, però redueix progressivament la velocitat dins un radi de frenada per aturar-se sense passar-se.
  • Pursuit / Evade: Prediu la posició futura de l'objectiu segons la seva velocitat actual per interceptar-lo.
  • Wander: Projecta un cercle davant l'agent i desplaça aleatòriament un punt sobre la seva circumferència per deambular de forma natural.

Comportaments de Grup (Flocking)

  • Separació (Separation): Força de repulsió respecte als veïns massa propers per evitar col·lisions.
  • Alineació (Alignment): Iguala la direcció i velocitat mitjana dels agents del voltant.
  • Cohesió (Cohesion): Empeny l'agent cap al centre de massa (posició mitjana) del grup.

Exemple de Codi: Seek, Arrive i Separació en C#

using System.Collections.Generic;
using UnityEngine;

public class SteeringAgent : MonoBehaviour
{
    public float maxSpeed = 6f;
    public float maxForce = 12f;
    public float slowingRadius = 3f;
    public float separationRadius = 1.8f;

    private Vector3 _velocity;

    public Vector3 Arrive(Vector3 targetPos)
    {
        Vector3 toTarget = targetPos - transform.position;
        float distance = toTarget.magnitude;
        if (distance < 0.05f) return Vector3.zero;

        // Redueix la velocitat si entra dins el radi de frenada
        float rampedSpeed = maxSpeed * (distance / slowingRadius);
        float clippedSpeed = Mathf.Min(rampedSpeed, maxSpeed);

        Vector3 desiredVelocity = (toTarget / distance) * clippedSpeed;
        return Vector3.ClampMagnitude(desiredVelocity - _velocity, maxForce);
    }

    public Vector3 Separation(List neighbors)
    {
        Vector3 steering = Vector3.zero;
        int count = 0;

        foreach (SteeringAgent other in neighbors)
        {
            if (other == this) continue;
            float dist = Vector3.Distance(transform.position, other.transform.position);
            if (dist > 0 && dist < separationRadius)
            {
                Vector3 pushDir = (transform.position - other.transform.position).normalized;
                steering += pushDir / dist; // Més fort com més a prop estigui
                count++;
            }
        }

        if (count > 0)
        {
            steering /= count;
            steering = steering.normalized * maxSpeed - _velocity;
            steering = Vector3.ClampMagnitude(steering, maxForce);
        }
        return steering;
    }

    public void ApplySteering(Vector3 totalForce)
    {
        _velocity = Vector3.ClampMagnitude(_velocity + totalForce * Time.deltaTime, maxSpeed);
        transform.position += _velocity * Time.deltaTime;

        if (_velocity.sqrMagnitude > 0.01f)
            transform.forward = Vector3.Slerp(transform.forward, _velocity.normalized, Time.deltaTime * 10f);
    }
}

Pathfinding: L'Algorisme A* (A-Star) des de Zero

Els Steering Behaviors fallen quan hi ha laberints o parets pel mig. Per trobar el camí més curt entre dos punts en un mapa discretitzat (graella o graf), l'estàndard de la indústria és l'algorisme A*, que combina el cost real recorregut amb una estimació heurística fins a la meta.

G Cost (Cost Acumulat) Distància exacta recorreguda des del node d'inici fins al node actual (10 en ortogonal, 14 en diagonal).
H Cost (Heurística) Estimació de la distància restant fins al node destí (Distància Manhattan o Diagonal/Octile).
F Cost = G + H Prioritat total del node. A* sempre explora primer el node de la Open List amb el F Cost més baix.

Implementació Completa d'A* sobre Graella 2D en C#

using System.Collections.Generic;
using UnityEngine;

public class PathNode
{
    public Vector2Int gridPos;
    public bool isWalkable;
    public int gCost;
    public int hCost;
    public int FCost => gCost + hCost;
    public PathNode parent;

    public PathNode(Vector2Int pos, bool walkable)
    {
        gridPos = pos;
        isWalkable = walkable;
    }
}

public class AStarPathfinder : MonoBehaviour
{
    public List FindPath(PathNode[,] grid, Vector2Int startPos, Vector2Int targetPos)
    {
        PathNode startNode = grid[startPos.x, startPos.y];
        PathNode targetNode = grid[targetPos.x, targetPos.y];

        List openSet = new List { startNode };
        HashSet closedSet = new HashSet();

        startNode.gCost = 0;
        startNode.hCost = GetDistance(startNode, targetNode);

        while (openSet.Count > 0)
        {
            // 1. Seleccionar el node amb menor FCost (i menor HCost en cas d'empat)
            PathNode currentNode = openSet[0];
            for (int i = 1; i < openSet.Count; i++)
            {
                if (openSet[i].FCost < currentNode.FCost ||
                   (openSet[i].FCost == currentNode.FCost && openSet[i].hCost < currentNode.hCost))
                {
                    currentNode = openSet[i];
                }
            }

            openSet.Remove(currentNode);
            closedSet.Add(currentNode);

            // 2. Hem arribat al destí? Reconstruïm el camí
            if (currentNode == targetNode)
                return RetracePath(startNode, targetNode);

            // 3. Avaluar tots els veïns transitable no visitats
            foreach (PathNode neighbor in GetNeighbors(grid, currentNode))
            {
                if (!neighbor.isWalkable || closedSet.Contains(neighbor))
                    continue;

                int newMovementCostToNeighbor = currentNode.gCost + GetDistance(currentNode, neighbor);
                if (newMovementCostToNeighbor < neighbor.gCost || !openSet.Contains(neighbor))
                {
                    neighbor.gCost = newMovementCostToNeighbor;
                    neighbor.hCost = GetDistance(neighbor, targetNode);
                    neighbor.parent = currentNode;

                    if (!openSet.Contains(neighbor))
                        openSet.Add(neighbor);
                }
            }
        }
        return null; // No existeix cap camí possible
    }

    private List RetracePath(PathNode startNode, PathNode endNode)
    {
        List path = new List();
        PathNode current = endNode;

        while (current != startNode)
        {
            path.Add(current);
            current = current.parent;
        }
        path.Reverse();
        return path;
    }

    private int GetDistance(PathNode a, PathNode b)
    {
        int dstX = Mathf.Abs(a.gridPos.x - b.gridPos.x);
        int dstY = Mathf.Abs(a.gridPos.y - b.gridPos.y);
        // Cost diagonal = 14, ortogonal = 10
        return dstX > dstY ? 14 * dstY + 10 * (dstX - dstY) : 14 * dstX + 10 * (dstY - dstX);
    }

    private List GetNeighbors(PathNode[,] grid, PathNode node)
    {
        List neighbors = new List();
        int width = grid.GetLength(0);
        int height = grid.GetLength(1);

        for (int x = -1; x <= 1; x++)
        {
            for (int y = -1; y <= 1; y++)
            {
                if (x == 0 && y == 0) continue;
                int checkX = node.gridPos.x + x;
                int checkY = node.gridPos.y + y;

                if (checkX >= 0 && checkX < width && checkY >= 0 && checkY < height)
                    neighbors.Add(grid[checkX, checkY]);
            }
        }
        return neighbors;
    }
}

Navegació 3D Professional amb `AI Navigation` (NavMesh)

En entorns 3D complexos, discretitzar el món amb una graella consumiria massa memòria. El paquet oficial AI Navigation de Unity transforma la geometria caminable de l'escena en una malla de polígons convexos (NavMesh) sobre la qual s'executa A* de manera ultraoptimitzada.

Components Principals

  • NavMeshSurface: Defineix quins objectes formen part de la superfície navegable i permet re-generar-la (Bake) en temps d'execució.
  • NavMeshAgent: Component de l'NPC que calcula la ruta, evita col·lisions locals (Obstacle Avoidance) i mou l'agent.
  • NavMeshModifier: Permet marcar zones específiques com a no caminables o assignar-los un cost d'àrea (ex: Aigua, Foc).

Obstacles Dinàmics i Salts

  • NavMeshObstacle: Per a portes corredisses o caixes mòbils. Activant Carving, l'obstacle forada dinàmicament el NavMesh perquè els agents recalculin la ruta.
  • NavMeshLink: Connecta dues superfícies separades (ex: saltar d'un balcó, creuar un abisme o pujar per una escala de mà).

Exemple de Codi: Control d'un NavMeshAgent i Punts de Patrulla

using UnityEngine;
using UnityEngine.AI;

[RequireComponent(typeof(NavMeshAgent))]
public class PatrolNavigator : MonoBehaviour
{
    [SerializeField] private Transform[] _waypoints;
    [SerializeField] private float _waypointTolerance = 0.5f;

    private NavMeshAgent _agent;
    private int _currentIndex = 0;

    private void Awake()
    {
        _agent = GetComponent();
    }

    private void Start()
    {
        if (_waypoints.Length > 0)
            _agent.SetDestination(_waypoints[0].position);
    }

    private void Update()
    {
        if (_waypoints.Length == 0) return;

        // Comprovar si l'agent ha acabat de calcular el camí i ha arribat al destí
        if (!_agent.pathPending && _agent.remainingDistance <= _waypointTolerance)
        {
            _currentIndex = (_currentIndex + 1) % _waypoints.Length;
            _agent.SetDestination(_waypoints[_currentIndex].position);
        }
    }
}

Arquitectura de Decisions I: Màquines d'Estats Finits (FSM)

Un error habitual és programar el comportament d'un enemic amb un switch o una cadena gegant d'if/else dins d'un únic Update(). Això genera codi espagueti impossible de mantenir. La solució professional és aplicar el Patró de Disseny State, encapsulant cada estat en la seva pròpia classe amb tres fases clares: Enter(), Tick() i Exit().

Exemple de Codi: Arquitectura FSM Modular en C#

using UnityEngine;

// 1. Contracte comú per a qualsevol estat
public interface IState
{
    void Enter();
    void Tick();
    void Exit();
}

// 2. Gestor de transicions d'estat
public class StateMachine
{
    public IState CurrentState { get; private set; }

    public void ChangeState(IState newState)
    {
        if (newState == null || newState == CurrentState) return;

        CurrentState?.Exit();
        CurrentState = newState;
        CurrentState.Enter();
    }

    public void Update()
    {
        CurrentState?.Tick();
    }
}

// 3. Exemple d'un Estat concret desacoplat
public class ChaseState : IState
{
    private readonly GuardAI _guard;

    public ChaseState(GuardAI guard) => _guard = guard;

    public void Enter()
    {
        _guard.Agent.speed = _guard.chaseSpeed;
        Debug.Log("Estat: PERSECUCIÓ iniciada!");
    }

    public void Tick()
    {
        if (_guard.Sensor.VisibleTarget != null)
        {
            _guard.Agent.SetDestination(_guard.Sensor.VisibleTarget.position);

            if (Vector3.Distance(_guard.transform.position, _guard.Sensor.VisibleTarget.position) <= _guard.attackRange)
                _guard.FSM.ChangeState(_guard.AttackState);
        }
        else
        {
            // Ha perdut de vista el jugador -> Passa a investigar l'última posició
            _guard.FSM.ChangeState(_guard.SearchState);
        }
    }

    public void Exit()
    {
        // Neteja d'animacions o efectes en sortir de l'estat
    }
}

Arquitectura de Decisions II: Behaviour Trees (Arbres de Comportament)

Quan un enemic té 15 o 20 comportaments diferents, les Màquines d'Estats Finits pateixen una explosió de transicions (tots els estats s'han de connectar amb tots). Els Behaviour Trees (BT) resolen aquest problema organitzant la lògica en un arbre jeràrquic modular de nodes reutilitzables i una memòria compartida anomenada Blackboard.

Nodes Compostos (Control de Flux)

Sequence (AND): Executa els fills d'esquerra a dreta fins que un falla (Failure). Si tots tenen èxit, retorna Success.

Selector (OR): Prova els fills fins que un té èxit (Success). Ideal per a prioritats (Ex: Curar-se -> Atacar -> Patrullar).

Decoradors (Modificadors)

Embolcallen un únic node fill per alterar-ne el resultat o l'execució: Inverter (converteix Success en Failure), Repeater o Cooldown.

Nodes Fulla (Execució)

Condition: Comprova una dada del Blackboard (ex: Vida < 30%).

Action: Executa una tasca real (ex: MoureACobertura) i retorna Running mentre dura.

1. Com funciona per dins: Mini-Framework de Behaviour Tree en C#

using System;
using System.Collections.Generic;

public enum NodeState { Running, Success, Failure }

public abstract class BTNode
{
    public abstract NodeState Evaluate();
}

// Node Compost: SEQUENCE (Tots els fills han de retornar Success)
public class Sequence : BTNode
{
    private readonly List _children;
    public Sequence(List children) => _children = children;

    public override NodeState Evaluate()
    {
        foreach (BTNode node in _children)
        {
            switch (node.Evaluate())
            {
                case NodeState.Failure: return NodeState.Failure;
                case NodeState.Running: return NodeState.Running;
            }
        }
        return NodeState.Success;
    }
}

// Node Compost: SELECTOR (El primer fill que retorni Success o Running guanya)
public class Selector : BTNode
{
    private readonly List _children;
    public Selector(List children) => _children = children;

    public override NodeState Evaluate()
    {
        foreach (BTNode node in _children)
        {
            switch (node.Evaluate())
            {
                case NodeState.Success: return NodeState.Success;
                case NodeState.Running: return NodeState.Running;
            }
        }
        return NodeState.Failure;
    }
}

// Node Fulla genèric per a Condicions o Accions ràpides
public class ActionNode : BTNode
{
    private readonly Func _action;
    public ActionNode(Func action) => _action = action;
    public override NodeState Evaluate() => _action();
}

2. Flux Professional amb l'Eina Oficial: Unity Behavior

Un cop entesa l'arquitectura interna de nodes, en producció utilitzem editors visuals perquè dissenyadors i programadors puguin depurar el flux en temps real. El paquet oficial Unity Behavior (com.unity.behavior, instal·lable des del Package Manager) integra:

  • Behavior Graph Editor: Editor visual de nodes amb depuració en viu durant el Play Mode (il·lumina quina branca s'està executant en cada fotograma).
  • Blackboard Integrat: Panell de variables tipades (GameObject, Vector3, float, bool) compartides entre tots els nodes del graf i modificables des de C#.
  • Custom Nodes en C#: Generació automàtica d'Action Nodes i Condition Nodes personalitzats amb l'atribut [SerializeReference].
using Unity.Behavior;
using UnityEngine;

// Exemple d'actualització d'una variable del Blackboard de Unity Behavior des de C#
public class EnemyBlackboardSync : MonoBehaviour
{
    [SerializeField] private BehaviorGraphAgent _behaviorAgent;
    [SerializeField] private FieldOfViewSensor _sensor;
    [SerializeField] private float _currentHealth = 100f;

    private void Update()
    {
        // Sincronitzem les dades dels sensors amb el Blackboard del graf visual
        _behaviorAgent.SetVariableValue("TargetPlayer", _sensor.VisibleTarget?.gameObject);
        _behaviorAgent.SetVariableValue("Health", _currentHealth);
    }
}
